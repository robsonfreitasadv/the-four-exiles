# Lore aprovado

Dossiês e textos de lore aprovados ficam aqui, um arquivo por tema (ex.: `grays.md`, `ilvani.md`, `censo-2049.md`).

- Escreva em português; o site traduz para o inglês quando o texto for publicado.
- No topo de cada arquivo, indique o status (aprovado, provisório) e a data.
- Rascunhos ainda em discussão podem ficar em `docs/lore/rascunhos/`.
- Ao aprovar algo, registre também em `docs/DECISOES.md`.
